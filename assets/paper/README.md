# Paper figure attribution

The images in this directory reproduce Figures 1 and 2 from:

Hejian Sang, Zhengze Zhou, Shayan Mohajer Hamidi, Xiaomin Li, Rohit Jain, and
Alborz Geramifard. **Composing What Each Teacher Learned: Multi-Teacher On-Policy
Distillation through Teacher-Relative Shifts.**
[arXiv:2610.10460v1](https://arxiv.org/abs/2610.10460v1), October 7, 2026.

The [paper](https://arxiv.org/html/2610.10460v1) is distributed under
[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
That license applies to these reproduced figures; the repository's Apache-2.0
software license does not replace it.
